# Vietnam Travel Reference Guides

Independent, plainly written reference guides for travellers entering Vietnam. Each guide is
compiled from currently published sources and states clearly where a figure comes from, so you
can check it yourself rather than take it on trust.

## Why these exist

Most entry problems are avoidable and happen before departure — a passport a few weeks short
of the six-month rule, an eVisa that was never printed, an entry port that does not match the
ticket. These guides focus on the details that actually stop trips.

## Sources and corrections

Figures are drawn from currently published guidance and are dated to 2026. Entry rules,
customs allowances and checkpoint lists change; always confirm against official sources before
you travel.

Found something out of date? Open an issue — corrections are welcome.
